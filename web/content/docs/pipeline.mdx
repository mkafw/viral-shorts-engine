## 各层职责

| 层 | 做什么 | 在哪 |
|----|--------|------|
| **剧本** | 故事本身（灵魂积碳12集） | 本手册各集MDX |
| **创作系统** | 剧本结构化：25线骨架定剧情、C/S/P/K锁一致性、白描转指令 | `/docs/creation-system` |
| **Prompt方法论** | 把白描指令翻译成AI视频模型能理解的5-stage prompt | `vendor/ai-shortfilm-prompts/` |
| **VSE流水线** | 调用AI模型生成视频、导出剪映草稿 | 本工程代码 |

## 实操流程（7步）

```
Step 1: 一句话核心          谁+处境+必须做什么+否则会怎样
Step 2: 结构化剧本          按[核心事件+关键场景+伏笔+基调]格式
Step 3: 清洗+白描化         华丽辞藻清洗器 → 白描转换器
Step 4: 视觉一致性锚点      主角代码/场景代码/道具代码 (C/S/P/K)
Step 5: 静态分镜提示词      AI绘图提示词万能公式：主体+动作+环境+光线+画幅
Step 6: 动态运镜补全        加上镜头运动+物理轨迹（5-stage Stage 4+5）
Step 7: 素材包输出          白描剧本 + 静态提示词 + 动态提示词 + 声音建议
```
