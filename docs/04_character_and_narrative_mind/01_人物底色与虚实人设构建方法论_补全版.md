## 零、核心逻辑链

**起点：寡情薄恩 → 忘恩负义 → 篡改是非 → 蒙蔽良知。**

- **正 / 中 / 反**是道德轴;
- **上 / 中 / 下 / 边缘**是阶层轴;
- **内 / 外**是表里轴;
- **前 / 中 / 后**是弧光轴;
- **三教九流**只是身份职业，不是底色。

身份只是舞台，底色决定他在压力下怎么选。
同样是商人：可以是仁厚儒商、务实自保、凉薄负义、野心进取。
同样是底层：可以是赤诚侠义、麻木从众、阴鸷记仇、混沌成长。
**真正全的是坐标组合，不是词表。**

> 人物 = 道德轴(正/中/反/灰) × 阶层轴(上/中/下/边缘) × 表里轴(内里/外显) × 弧光轴(前/中/后) × 关系轴(恩/仇/利/情)

**边界定义**：只管"角色骨子里是什么人"，不管具体行为、对白、情节。它是角色的出厂设置，改起来极难。

**功能属性**：输入灵魂驱动和世界观，输出角色的本性底色、道德边界、行为逻辑。

## 一、人物底色三大类

| 大类 | 内核 | 常见底色 | 特点 |
|------|------|----------|------|
| **正面** | 向善、担当、守护 | 仁厚担当、刚正守义、温润坚韧、赤诚热血、聪慧通透、孤勇叛逆、克己自律、悲悯救赎、豁达乐观、谨慎务实 | 有缺陷但选择向善 |
| **中性** | 先保自己、不害人 | 务实自保、疏离旁观、利己不损人、随波逐流、理性冷感、圆滑世故、摇摆矛盾、野心进取、享乐避苦、混沌未定 | 可转正可转反 |
| **反派** | 被三不知蒙蔽 | 凉薄负义、狂妄自负、阴鸷猜忌、贪婪私欲、虚伪城府、暴戾狠戾、叙事操控、寄生反噬、权力成瘾、伪殉道 | 慧根被蒙蔽，非纸片人式坏 |

## 二、正面底色库

| 底色类型 | 内核 | 常见行为 | 阴影/缺陷 | 弧光方向 |
|---|---|---|---|---|
| 仁厚担当型 | 悲悯 + 责任 | 护弱、扛事、修复关系 | 过度牺牲、被利用 | 学会边界 |
| 刚正守义型 | 原则高于利益 | 直言、抗恶、守规矩 | 僵化、不懂灰度 | 理解复杂人性 |
| 温润坚韧型 | 柔韧、长期主义 | 忍辱负重、默默修复 | 压抑、爆发晚 | 学会表达自我 |
| 赤诚热血型 | 情感浓烈、正义冲动 | 冲锋、救人、破局 | 鲁莽、被煽动 | 学会策略 |
| 聪慧通透型 | 洞察、理性 | 看破、布局、点醒他人 | 冷眼、犬儒 | 重新入世 |
| 孤勇叛逆型 | 自由、反权威 | 破局、挑战旧秩序 | 孤独、破坏性 | 建立归属 |
| 克己自律型 | 秩序、责任 | 守戒、自省、稳定团队 | 苛责、僵化 | 学会宽容 |
| 悲悯救赎型 | 负罪感 + 共情 | 赎罪、救弱、自我惩罚 | 沉溺过去 | 原谅自己 |
| 豁达乐观型 | 希望、生命力 | 感染他人、坚持 | 逃避沉重 | 直面黑暗 |
| 谨慎务实型 | 生存智慧 | 权衡、保全、稳扎稳打 | 怯懦、短视 | 关键时刻担当 |

> 正面底色不是"完美"，而是**有缺陷但选择向善**。正面人物最好也有一层阴影，否则会假。

## 三、中性底色库

| 底色类型 | 内核 | 常见行为 | 可转正 | 可转反 |
|---|---|---|---|---|
| 务实自保型 | 先保自己 | 不害人，但不冒险 | 被逼出担当 | 倒向强权 |
| 疏离旁观型 | 情感低耗 | 不站队、见证 | 被真情唤醒 | 冷漠纵容 |
| 利己不损人型 | 交易型 | 讲规则、算得失 | 建立底线 | 利益够大就越界 |
| 随波逐流型 | 群体认同 | 跟风、从众 | 被启蒙 | 被叙事操控 |
| 理性冷感型 | 逻辑优先 | 分析、旁观 | 学会共情 | 变成冷酷工具人 |
| 圆滑世故型 | 人情高手 | 左右逢源 | 用世故护善 | 用世故助恶 |
| 摇摆矛盾型 | 善恶拉扯 | 反复、犹豫 | 成长为主角 | 堕落为反派 |
| 野心进取型 | 想往上爬 | 抓机会、经营人脉 | 以野心成大事 | 不择手段 |
| 享乐避苦型 | 追求舒服 | 逃避、拖延 | 危机中觉醒 | 出卖他人换安逸 |
| 混沌未定型 | 尚未觉醒 | 被环境塑造 | 被善引导 | 被恶吞噬 |

> 中性底色最适合写"普通人被卷入故事"。
> 主角若一开始是中性务实，后来一步步变成反派，会更真实。

## 四、反派底色库

### 4.1 反派六底色（原有完整版）

| 底色 | 内核 | 行为表现 | 身体特征 |
|------|------|----------|----------|
| **凉薄负义型** | 不懂感恩，利益高于情义 | 有利可图和善，利益冲突立刻反噬 | 说话时喉咙滑，手心冷 |
| **狂妄自负型** | 极度自我崇拜，错永远是别人 | 听不进真话，为脸面篡改事实 | 下颌绷紧，目光俯视 |
| **阴鸷猜忌型** | 内心阴暗，不信任任何人 | 记仇记恨，把威胁者污名化 | 眼神躲闪，后颈发紧 |
| **贪婪私欲型** | 一切为攫取权势钱财 | 道义可以全部牺牲 | 手指蜷曲，瞳孔放大 |
| **虚伪城府型** | 天生擅长伪装，本心冷漠 | 外宽内忌，面善心险 | 嘴角笑，眼睛不笑 |
| **暴戾狠戾型** | 情绪凶暴，崇尚力量 | 直接暴力压制，不屑伪装 | 太阳穴跳，拳头攥紧 |

### 4.2 反派再补四类（贴合"篡改是非、蒙蔽良知"逻辑）

| 类型 | 内核 | 手段 | 目的 |
|---|---|---|---|
| **叙事操控型** | 垄断解释权 | 立碑、讲堂、改口述、受害者有罪论 | 让人相信他才是恩人 |
| **寄生反噬型** | 靠吸恩人血上位 | 先依附、后夺权、再污名化恩人 | 抹掉亏欠，独占利益 |
| **权力成瘾型** | 不能失去控制 | 制造恐惧、拉拢告密者 | 维持权威 |
| **伪殉道型** | 把自己包装成牺牲者 | 卖惨、煽情、道德绑架 | 让人自愿服从 |

> "被全村救过命，发家后霸占水源，编造当年施舍村民"的角色，最准确的组合是：
> **底色：凉薄负义 + 叙事操控 + 贪慕虚名**
> **手段：居功掩过、文过饰非、颠倒黑白、受害者有罪论**
> **目的：欺世盗名、蒙蔽良知、让恩人反成罪人**

## 六、四轴坐标表

原"三维坐标"升级为"四轴坐标"。

| 轴 | 分层 | 写作问题 |
|---|---|---|
| **道德轴** | 正 / 中 / 反 / 灰 | 他底线在哪？ |
| **阶层轴** | 上 / 中 / 下 / 边缘 | 他手里有什么资源？ |
| **表里轴** | 内里底色 / 外在面具 / 公众人设 / 私密面目 | 他演给谁看？ |
| **弧光轴** | 前史 / 触发 / 转折 / 终局 | 他如何变？ |

**命名建议**：若"左内右外"指表里，改叫**内里—外显**；若指立场，用**利他—利己、守序—破序**，比左右更好写。

**示例组合**：

- 下层出身 + 中性务实 + 外热心内冷 + 前善后恶 = 被权力腐蚀的告密者。
- 上层权贵 + 反派凉薄 + 外仁内毒 + 前隐后显 = 居功掩过的乡贤。
- 中层职业 + 摇摆矛盾 + 内外不一 + 前懦后勇 = 成长型主角。
- 边缘人 + 孤勇叛逆 + 外冷内热 + 前孤后归 = 侠义型主角。

## 七、人物深层模块

底色是"他是什么人"，深层模块是"他为什么成为这种人"。

| 模块 | 边界定义 | 功能属性 | 核心问题 |
|------|----------|----------|----------|
| **创伤** | 只管童年被弃/饥荒/背叛/羞辱 | 创伤事件 → 性格底色 | 他受过什么伤？ |
| **欲望** | 只管权/钱/名/爱/认可/控制/安全感/被看见 | 深层渴望 → 行为驱动力 | 他真正想要什么？ |
| **恐惧** | 只管怕穷/怕死/怕被看穿/怕失去权力/怕回底层 | 最怕的事 → 不可触碰的禁区 | 他最怕什么？ |
| **羞耻与秘密** | 只管最不想让人知道的事 | 秘密 → 作恶发动机 | 他藏了什么？ |
| **执念** | 只管一定要证明/赢/抹掉的事 | 偏执 → 不可动摇的执念 | 他放不下什么？ |
| **道德底线** | 只管做什么会犹豫、什么绝不碰、底线怎么降 | 底线 → 抉择极限 | 他被逼到哪一步？ |
| **自我欺骗** | 只管他是否真觉得自己是好人 | 自我合理化 → 伪善深度 | 他怎么骗自己？ |
| **依恋模式** | 只管安全/焦虑/回避/混乱型 | 依恋类型 → 对待恩人/敌人的方式 | 他怎么对待亲密关系？ |
| **防御机制** | 只管否认/投射/合理化/转移/升华 | 心理保护 → 行为合理化 | 他怎么为自己辩解？ |
| **软肋与盲点** | 只管一个人/一件事/一个词能让他失控 | 致命弱点 → 冲突爆破点 | 什么能让他失控？ |
| **身体与疾病** | 只管残疾/病痛/衰老/外貌焦虑 | 身体处境 → 性格改写 | 他的身体怎么塑造他？ |
| **智商/情商/逆商** | 只管聪明/愚笨/冷酷/善良组合 | 能力组合 → 行为方式 | 他靠什么活？ |

## 八、二元维度

| 维度对 | 写作问题 |
|---|---|
| 虚实 | 哪层是真，哪层是演？ |
| 内外 | 内里底色 vs 外在面具差多远？ |
| 整体局部 | 他在大局面和小细节里是不是同一个人？ |
| 前后 | 同一场景，前后两次选择差在哪？ |
| 显隐 | 什么摆上台面，什么藏在底下？ |
| 公私 | 公众人设 vs 私密面目差多远？ |
| 得失 | 他算的是眼前的利，还是长远的局？ |
| 恒变 | 他身上什么永远不变，什么一直在变？ |
| 真伪 | 他的恩情、罪名、历史，哪些是真的？ |
| 大小 | 大事小事上，他是同一个人吗？ |
| 动静 | 他什么时候动，什么时候忍？ |

## 九、面由心生与换装神情

| 模块 | 边界定义 | 功能属性 | 核心问题 |
|------|----------|----------|----------|
| **面由心生** | 只管底色映射面相眼神气场（含微表情、体态） | 底色 → 面相/眼神/气场 | 他的脸暴露了什么？ |
| **换装与神情** | 只管两套表情系统 | 伪装脸 vs 本相脸 | 他什么时候卸下面具？ |

**微表情参考**：嘴角抽动、瞳孔变化、吞咽、手指收紧。
**动作习惯参考**：摸戒指、转茶杯、咳嗽、假笑、避开眼神。

## 十、社会关系网

人不是孤岛。"上下、内外、前后"之外，还缺**关系结构**。

- **家族谱系**：父辈恩怨、宗族规矩、遗产、门第、联姻。
- **恩仇网络**：谁救过谁、谁欠谁、谁背叛谁、谁握谁把柄。
- **利益链**：钱从哪来、权从哪来、谁离不开谁。
- **派系与站队**：官场、商场、江湖、学校、军队、宗教团体。
- **师承与门徒**：谁教他、谁影响他、谁被他利用。
- **人情债与道德账本**：恩情在村里、族里、江湖里怎么算。
- **盟友与敌人**：表面盟友、潜在敌人、双面间谍、骑墙派。
- **替罪羊机制**：谁被推出去背锅？谁被污名化？
- **社会性死亡**：造谣、孤立、贴标签、断生计，比杀人更狠。
- **群像功能**：每个配角承担什么功能？见证者、帮凶、受害者、反抗者、沉默大多数。

## 十一、权力与制度

恶需要土壤。"霸占水源、立碑、讲堂" = **权力 + 叙事 + 制度**的组合。

- **权力层级**：谁掌握水源、土地、粮食、武力、话语、审批。
- **法律与规则**：正式法律、乡规民约、江湖规矩、潜规则。
- **经济结构**：资源稀缺、饥荒、商路、税收、地租、高利贷。
- **媒介与宣传**：碑、讲堂、戏台、茶馆、报纸、广播、网络、短视频。
- **教育洗脑**：从孩子开始改记忆，最可怕。
- **宗教与信仰**：因果报应、天命、神谕、忏悔、赎罪。
- **宗族与乡土**：面子、香火、祠堂、族谱、口述史。
- **官商勾结**：保护伞、利益输送、白手套。
- **信息茧房**：只让村民听到一种版本。
- **集体记忆政治**：谁有权写历史，谁就有权定义善恶。

## 十二、叙事与操控

"篡改是非、蒙蔽良知"本质是**叙事权争夺**。

- **不可靠叙述**：故事由谁讲？他有没有撒谎？
- **视角操控**：读者跟谁走？先信谁？后来发现真相？
- **信息差**：角色知道什么、不知道什么、误以为什么。
- **谣言机制**：谣言怎么起、怎么传、怎么被权威背书。
- **煤气灯效应**：让受害者怀疑自己记忆。
- **受害者有罪论**：把恩人变成贪得无厌的人。
- **污名化**：贴标签、起外号、翻旧账、造黑料。
- **仪式与符号**：立碑、挂匾、塑像、开大会、唱赞歌。
- **档案与口述**：烧旧档、改族谱、收买老人、威胁知情人。
- **反转与伏笔**：真相藏在哪个物件、哪句话、哪个人身上。

---

## 十三、时间与弧光

人怎么变坏 / 变好：

- **前史**：他受过什么恩？为什么忘恩？
- **触发事件**：哪件事让他决定反噬？
- **渐变节点**：第一次撒谎、第一次夺利、第一次害人。
- **堕落台阶**：每一步都"不得不"，最后回不了头。
- **高峰与崩塌**：最得意时埋下最大危机。
- **终局**：报应、逃脱、被反噬、被原谅、被遗忘。
- **前后对照**：同一场景，前后两次选择不同，人物就立住了。
- **代价**：他失去什么？亲情、睡眠、名声、健康、灵魂。

## 十四、空间物象与身体语言

- **空间**：老宅、祠堂、水源、碑、讲堂、桥、田、山、牢。
- **物象**：玉佩、账本、旧信、锄头、水契、族谱、照片。
- **色彩**：灰、红、金、黑，对应压抑、权力、贪婪、死亡。
- **声音**：水声、诵经、戏文、广播、窃窃私语。
- **气味**：泥土、香火、药、血、霉味。
- **动作习惯**：摸戒指、转茶杯、咳嗽、假笑、避开眼神。
- **微表情**：嘴角抽动、瞳孔变化、吞咽、手指收紧。
- **语言风格**：口音、口头禅、官腔、乡音、黑话、敬语。
- **身体状态**：胖瘦、伤疤、跛脚、老茧、衣着整洁或邋遢。

## 十五、主题与伦理

别把恶写浅：

- **主题母题**：恩将仇报、记忆篡改、权力腐蚀、群体盲从、正义迟到。
- **伦理立场**：你是在展示恶，还是在美化恶？
- **反派自洽**：他必须有一套自己的逻辑，哪怕扭曲。
- **受害者主体性**：受害者不能只是工具，要有反抗、沉默、妥协、觉醒。
- **不消费苦难**：写痛要准，不要猎奇。
- **文化尊重**：乡村、宗族、宗教、少数民族，别乱贴标签。
- **历史敏感**：涉及真实事件要谨慎。
- **留白**：最深的恶，往往不直接写，让读者自己脊背发凉。

**尤其该补的六块**（对应"寡情薄恩→篡改是非→蒙蔽良知"逻辑）：

1. **恩情债务系统**：恩情怎么欠、怎么还、怎么被赖、怎么被反咬。
2. **叙事权争夺**：谁有资格讲过去，谁被消音。
3. **群体心理**：村民为什么信？因为怕、因为利、因为从众。
4. **制度保护伞**：他为什么能霸水源、立碑、开讲堂。
5. **受害者困境**：老人为什么不敢说真话？说了会怎样？
6. **反派自欺**：他如何说服自己"我才是受害者/施恩者"。

## 十六、人设卡模板

## 十九、创作链路

人物底色系统在七层框架中属于**结构层**，是"人物生命化"的核心模块组。24 线是骨架，人物底色是**骨血**。调用时排在"搭骨架"之前：

```
第一步：问本心（哲学层）——我此刻最真的东西是什么？
第二步：定底色（结构层·人物底色系统）——他是谁？
第三步：搭骨架（结构层·24线）——故事往哪走？
第四步：找感觉（感官层）——身体哪里最先有感觉？
第五步：设冲突（驱动层）——什么在阻止？什么在打破？
第六步：落笔写（表达层）——低用赋，高用比，转折用兴。
第七步：加商业（商业层）——信息掰开喂，憋屈铺足再引爆。
第八步：查保护（保护层）——有什么不该说破？有什么该砍掉？
```

## 二十、理论参考

可选，不必全用：

- **心理学**：马斯洛需求、依恋理论、大五人格、荣格阴影、防御机制。
- **社会学**：差序格局、社会交换、布迪厄资本、福柯话语权、集体记忆。
- **叙事学**：普罗普功能、坎贝尔英雄之旅、格雷马斯行动元、不可靠叙述。
- **编剧**：人物弧光、压力选择、欲望-恐惧-秘密表、场景-反应。
- **传播学**：沉默螺旋、议程设置、谣言公式、信息茧房。

---

> **最后一句**：你已有的框架是**人物底色 + 行为手段 + 目的 + 坐标 + 呈现**。
> 补全后加入的是：**创伤欲望、关系网络、权力制度、叙事操控、时间弧光、空间物象、主题伦理、理论工具**。
> 不是词不够，是维度要全——底色决定选择，维度让人活起来。
