# Integration

Recommended integration sequence:

1. Parse natural-language story.
2. Create stable assets.
3. Build causal graph.
4. Build blocking.
5. Plan camera-first shots.
6. Build performance and voice.
7. Populate prompt layers.
8. Run validation.
9. Compile model-specific final prompt.
10. Store the structured source alongside the final prompt.

Keep the structured YAML/JSON as the editable source of truth.
