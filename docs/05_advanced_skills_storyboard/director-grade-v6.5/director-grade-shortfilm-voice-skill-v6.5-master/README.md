# Director-Grade Shortfilm Voice Skill v6.2

v6.2 adds a Prompt Layering Compiler: prompts are compiled from outside to inside, like nested layers. It connects GLOBAL consistency, scene, camera-first directing, blocking, action, gaze, performance, voice/sound, micro-details, continuity, and Hooks.

Core principle:

STORY → BEHAVIOR → BLOCKING → CAMERA OBSERVATION → PERFORMANCE → SHOT CHAIN → PROMPT LAYERS → FINAL PROMPT

Prompt layers are a compilation format, not a replacement for directing logic.
