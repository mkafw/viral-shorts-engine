# Tutorial 67 — Seedance 分层写法：提取结果

> 来源：用户上传《67-模型-Seedance分层写法.mp4》
> 本文件只记录目前通过视频画面/OCR实际提取到的内容；没有把未验证的内容当成视频原话。

## 1. 视频中明确出现的核心框架

视频把提示词/导演信息拆成多个控制面，而不是只写一句“画一个镜头”。

实际画面中出现的主要模块：

1. 摄影参数及画面质量
2. 整体情绪
3. 人物状态
4. 场景
5. 镜头运镜
6. 重要限制
7. 声音
8. 画面内容（分段式叙事）

示例中还使用了：
- 0–5 秒：建立环境
- 5–10 秒：人物进入
- 10–15 秒：情绪表达
- 15–20 秒：故事暗示

这说明“分层”不仅是视觉形容词分层，还包含**镜头、人物、场景、声音、时间段和限制条件**。

## 2. 视频中的基础运镜

画面明确展示了：
- 缓慢推镜头：平缓推进、锁定主体；用于放大情绪、突出细节、铺垫悬念
- 快速推镜头：急速切入、紧张压迫、视觉冲击；示例为快速接近并定格惊慌神态
- 缓慢拉镜头：缓缓拉远、展露环境、全景呈现；用于孤寂、宏大、疏离感
- 水平摇镜（左右）：横向摇移、跟随人物、场景衔接；可用于跟拍行进、展示全貌、自然转场

视频示例中的写法会把“运镜 + 主体 + 情绪/效果 + 画幅/画质”等信息组合起来。

## 3. 复杂运镜必须拆解

视频后段明确提出：
- 第一：镜头从哪里开始
- 第二：画面里谁是主角

结合后面的案例，复杂运镜不应只写“镜头很酷地移动”，而应拆成可执行的镜头状态：
- 起始位置
- 起始观察对象
- 主体是谁
- 镜头路径/方向
- 运动速度
- 观察对象如何变化
- 最终停在哪里
- 最终画面是什么

## 4. 结尾画面锁定

视频画面明确出现：
“**一定要锁住结尾的画面**”

随后强调：
“**前后画面就能顺畅衔接 / 短片也能持续加长**”

因此 v6.3 把 END_FRAME_LOCK 作为独立控制层：
SHOT[n].END_FRAME
→ SHOT[n+1].START_STATE

这不是普通的“连续性提醒”，而是下一镜头的输入状态。

## 5. 剪辑/转场语言

视频明确展示：
- DOLLY IN / 推轨推进
- RACK FOCUS / 焦点转移
- L-CUT / 声音延续
- HARD CUT / 硬切
- J-CUT / 声音先入
- MATCH CUT / 匹配剪辑
- SMASH CUT / 突切
- HIDDEN CUT / 隐藏剪辑

因此 v6.3 新增 EDITING_TRANSITION 层。

注意：这些属于**镜头之间的关系**，不能和单镜头 CAMERA_LANGUAGE 混成一个字段。

## 6. 视频案例中的“现实电影”约束

案例画面明确出现的约束包括：
- 真实电影摄影风格
- 真人实拍质感
- 非 CG 渲染感
- 纪录片式抓拍
- 电影级动态范围
- 高真实度环境
- ARRI Alexa 35 / RED V-Raptor 质感
- 35mm 电影镜头，部分 85mm 浅景深人像镜头
- f/1.8–f/2.8

同时强调：
- 真实皮肤和布料纹理
- 自然光影
- 真实环境比例
- 人物动作符合真实物理规律
- 禁止游戏 CG、二次元动画感等

这些属于 GLOBAL / CAMERA / CONSTRAINTS，而不是每个动作都重复写。

## 7. 声音层

案例中明确出现：
- 铁门生锈摩擦声
- 老建筑木板轻微响动
- 远处海鸟叫声
- 女主脚步回响
- 低频环境氛围
- 微弱弦乐铺垫心理紧张
- 避免爆炸式音乐、商业大片配乐感

因此声音应保留“来源 → 声音 → 情绪作用”的关系。

## 8. 与本 Skill 的融合结论

教程的“分层写法”与 v6 的“导演控制树”不是二选一：

导演控制树：
STORY → BEHAVIOR → BLOCKING → CAMERA → PERFORMANCE → SOUND

教程分层：
摄影参数/整体情绪/人物/场景/运镜/限制/声音/分段叙事

v6.3 采用“双树”：

A. 导演源树：决定发生什么。
B. Prompt 编译树：决定这些决定如何组织成 Seedance 可执行输入。

最终：
导演源树
→ Seedance 分层映射
→ 镜头级 Prompt
→ END_FRAME_LOCK
→ 下一镜 START_STATE
→ EDITING_TRANSITION
→ 连续短片
