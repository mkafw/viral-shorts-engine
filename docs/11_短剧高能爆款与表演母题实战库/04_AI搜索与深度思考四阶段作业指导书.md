# 🧠 AI 搜索（Search）与深度思考（Thinking）四阶段作业指导书

> **定位**：规范大模型在不同短剧生产环节中的能力调度。解决“在不需要思考的地方乱幻觉、在需要深度推演的地方太浮躁”的问题。

---

## 🧭 四大阶段能力路由总表

| 阶段 | 生产任务 | 核心调用能力 | 严禁行为 |
| :--- | :--- | :--- | :--- |
| **阶段 1：选题与脑洞** | 抓取全网爆款榜、违规下架案例、热点梗 | **主力：全网深度搜索 Search** | 严禁完全凭空捏造未验证过的新题材 |
| **阶段 2：剧本与逻辑推演** | 八节拍骨架、断章悬念、暗线闭环、潜台词 | **主力：慢思考 Thinking / CoT** | 严禁跳过大纲直接一键出正文 |
| **阶段 3：微表情解构** | 把抽象情绪翻译为肌肉、眼球、肢体三部曲 | **混合：Thinking 生理学拆解** | 严禁写“他很愤怒”等空洞文学词 |
| **阶段 4：分镜 Prompt 编译** | 转化为英文 8 段式、硬锁、负面清单 | **纯机械 Hard Lock（关闭发散）** | 严禁模型在此时加入任何主观哲学发挥 |

---

## 📋 各阶段标准化作业流程（SOP）

### 阶段 1：Search 驱动的选题情报 SOP
1. 调用 Search 检索：“2026年最新爆款短剧榜单 前十名题材与核心钩子”。
2. 调用 Search 检索：“近期短剧下架违规通报与禁发题材词库”。
3. 提炼出本片的【题材反差公式】：`常规身份 + 极端反常逆境 + 超能/财富外挂`。

### 阶段 2：Thinking 驱动的剧本深度推演 SOP
1. 启动 Thinking 推演：
   - 观众在第 3 秒凭什么停下手指？
   - 主角面临的困境为什么常规逻辑解不开？
   - 这场戏明面台词是什么？主角内心真实的杀机（潜台词）是什么？
2. 锁定第 55~60 秒的断章卡点，确保悬念无法用一句话剧透。

### 阶段 3：Thinking 驱动的微表情拆解 SOP
1. 将编剧给出的情绪状态，拆解为解剖学肌肉运动：
   - 示例（强装镇定）：
     - 步骤 1：咬紧后槽牙导致下颌紧绷。
     - 步骤 2：喉结上下滑动吞咽唾沫。
     - 步骤 3：极快眨眼两次后眼球斜视。

### 阶段 4：Hard Lock 严格编译 SOP
1. 将拆解后的微动作填入八段式的 `[5 表演与台词]`。
2. 强制补齐 `[7 硬锁 HARD LOCK]` 与 `[8 负面清单 NEGATIVES]`。
3. 全文英文输出，直接送入图生视频引擎。
