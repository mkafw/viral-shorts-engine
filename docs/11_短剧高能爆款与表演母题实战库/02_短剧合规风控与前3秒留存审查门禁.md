# 🛡️ 短剧平台合规风控与前 3 秒留存审查门禁

> **定位**：AI 短剧商业化的“生死线”。解决①投流封号限流风险 ②前3秒观众滑走低留存问题。

---

## 🚫 一、平台合规双红线排查（微信/抖音/快手短剧底线）

短剧在输出分镜前，必须经过合规审查员（Compliance Auditor）的脱敏置换：

| 违规/高危类别 | 原始高危写法 | 商业合规脱敏替换法 |
| :--- | :--- | :--- |
| **过度血腥暴戾** | 砍断手臂、血肉模糊、大量喷血 | 冲击波震飞、黑白色调打击、镜头切向墙面影子飞溅、音效卡点替代直面血腥 |
| **违背公序良俗** | 真实公职人员腐败、黑帮血拼、校园霸凌致死 | 虚构架空世界观（如“天海财阀争霸”）、商界博弈、合法商战对抗 |
| **低俗封建迷信** | 算命改命、真正下蛊降头、活人献祭 | 古代传统非遗医学针灸、心理暗示疗法、悬疑解密幻象 |
| **敏感词违禁** | 杀人、首富、赌博、极度侮辱性谩骂 | 制裁、领军人物、对决、戏剧性反讽台词 |

---

## ⏱️ 二、网感前 3 秒留存审查卡（三秒不炸直接退单打回）

短剧前 3 秒如果平铺直叙，完播率直接腰斩。编剧提交剧本必须满足以下 **至少 2 项**，否则门禁打回：

- [ ] **视觉奇观突入**：开局第一帧就是特写或极端动态（如枪口顶脑门、摔碎的千万支票、悬空脚尖）。
- [ ] **反常识人设暴露**：乞丐开着法拉利收废品、首富在路边被保安撕毁请柬。
- [ ] **高压紧迫倒计时**：“还有 30 秒，如果不签下这份协议，整座大厦将从地图上抹去”。
- [ ] **直接打脸爆破**：前 1.5 秒耳光声落，紧接着受害者极其诡异的抬头冷笑。

---

## 📈 三、爽点密度与断章卡点节奏表

- **0~3s（生死钩子）**：制造致命悬念与反差冲突。
- **15s（第一小爽点）**：主角初步反击或小人物露脸打脸反派狗腿。
- **30s（危机升级）**：大反派真正登场，带来压倒性绝望。
- **45s（底牌揭露）**：主角亮出震撼身份的一角。
- **55~60s（黄金断章崖）**：在子弹即将出膛、大门即将推开、耳光即将落下的瞬间 **戛然而止**，屏幕黑屏弹入下集预告。
