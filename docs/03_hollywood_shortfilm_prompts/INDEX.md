# 好莱坞级 AI 短片提示词方法论与案例库 (Hollywood AI Short Film Prompt System)

> **核心源起**：基于好莱坞导演 PJ Ace 盛赞的《丧尸清道夫》（Zombie Scavenger）全案拆解与 AI 短片提示词工业级实战方法论。
> **目标**：彻底告别抽卡、消除塑料感、杜绝动作变形与人物漂移，实现“可控分镜出片”。
