# 05 自动化对接与标准 JSON (Pipeline API Schema)

> **定位**：打通 Google Flow 资产标签、剪映 cutcli 自动打轴、八项出图质检门禁与统一数据 JSON 结构。  
> **适用环境**：本地 `viral-shorts-engine`、一键脚本 `drama-pipeline.mjs` 以及 Gemini 网页端结构化输出。

---

## 一、Google Flow 资产锚定铁律（必须严格执行）

在使用 Google Flow（或类似多图参考的视频大模型）时，模型对引用的资产有严格的标记语法要求：

1. **角色资产命名与引用**：
   - 资产库内命名：必须为纯净中文或特定英文标识，如 `[陆辰]`。
   - 提示词中引用：一律使用 `{@角色名}`（如 `{@陆辰}`、`{@苏晴}`）。
   - **严禁改名**：不能在提示词中写成 `{@身穿西装的陆辰}` 或 `{@男主陆辰}`，这会导致 Flow 无法索引到参考图而变脸。
2. **场景资产命名与引用**：
   - 全局通用主场景一律标注为 `{@场景}`。
   - 分镜独立场景标注为 `{@场景_S0}`、`{@场景_S1}`。
3. **空间布局与调度图引用**：
   - 3D/2.5D 场景调度俯视图统一标注为 `{@Layout_XXXXXX}`（引用布局预设）。
4. **视频生成提示词禁忌**：
   - 直接喂给视频模型（Veo / Sora）的 `videoPrompt` **禁用 `{@}` 语法**，必须由引擎转译为纯自然语言与平缓克制的动作描述。

## 二、剪映 / CapCut 草稿字幕与打轴规范

由脚本自动化创建剪映工程草稿时，时间轴以**微秒（Microseconds, $1\text{s} = 1,000,000\mu\text{s}$）**为基准：

- **单句台词时长标准**：
  - 中文台词朗读标准语速约为每秒 3.5 ~ 4 个字。
  - 单镜头台词时长控制在 2.5 秒 ~ 6.0 秒之间，避免单句台词超时造成视觉停滞。
- **短剧花字样式标准**：
  - 字号：`9` ~ `10` 号标准短剧字号；
  - 样式：粗体加黑（Bold）；
  - 配色：纯白文字（`#FFFFFF`）+ 黑色描边（`#000000`，描边宽度 2）+ 底部柔和投影（Shadow），确保在任何复杂背景画面下均清晰可读。

## 三、八项报错出图质检门禁 (Eight-Error Gate)

在将分镜提示词送入出图引擎前，必须经由质检门禁。任何一项触发即判定 **REJECT**，必须修改后方可出图：

| 序号 | 质检项 | 判定标准 | 常见翻车表现 |
| :--- | :--- | :--- | :--- |
| **01** | **抽象文学词拦截** | 严禁无法被光学镜头捕捉的心态词 | 出现“排山倒海”、“杀气弥漫”、“气场两米八” |
| **02** | **肢体结构稳定性** | 禁止多角色在同一特写镜头中复杂缠绕 | 出现“两人激烈扭打握住对方手腕”极易崩出六指或多手 |
| **03** | **道具凭空出现** | 分镜中出现的关键道具必须在上一分镜有交代 | 突然从背后掏出从未提及的大物件 |
| **04** | **光影空间跳跃** | 相邻分镜间光源方向、色温不能突变 | 上一镜还是冷色夕阳，下一镜突然变成无阴影正午大太阳 |
| **05** | **景别违背空间逻辑** | 镜头推移与物理位置不符 | 角色在门外，镜头却越过实体墙直接特写室内 |
| **06** | **时间轴冲突** | 动作描述超出镜头时长容量 | 在 3 秒分镜里要求角色“进门、脱鞋、走上楼梯并推开卧室门” |
| **07** | **未绑定的角色名** | 出现未在资产库中定义的新角色 | 突然出现“路人乙冷冷一笑”却无角色设定 |
| **08** | **背景噪点与文字残留**| 画面背景不能含有任何随机字符或路牌文字 | 出现“乱码霓虹灯招牌”破坏真实沉浸感 |
