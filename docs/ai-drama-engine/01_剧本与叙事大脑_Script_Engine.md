# 01 剧本与叙事大脑 (Script Engine)

> **定位**：选题立项、80集大纲规划、黄金开局钩子、人物关系、分集剧本与台词质感。  
> **理论基石**：`DeepSeek - 故事创作二十三线卡`、`现实癫文短剧创作指南`、`四十二层洋葱引擎`、`自心写作系统`。

## 一、现实癫文选题法（现实锚点 × 癫化类型）

### 1.1 核心公式
$$\text{爆款短剧选题} = \text{现实可信锚点（路人3秒看懂）} \times \text{类型规则颠覆（内行10秒意外）}$$

- **现实锚点库（必须落地到具体实物或行为）**：
  张阿姨式极省、帮衬子女怕拖累、口头承诺无字据、保单/合同小字、垃圾袋碎片、狗不吃测毒、高糖口服液、药水牛肉、九楼执念、铁盒藏私房钱、小周笔记本暗线、怀孕儿媳扔垃圾。
- **癫化类型库**：
  修仙、克苏鲁、赛博朋克、规则怪谈、无限流、宫斗、神话、末日废土、特工、丧尸。
- **两道硬核验收测试**：
  - **3 秒测试**：路人能否立刻看清“谁在省、为谁、被谁骗”？说不出来就是锚点悬空。
  - **10 秒测试**：类型是否真的改变了规则，而不是仅仅“换了身衣服/换了职业”？

### 1.2 选题提示词模板（可直接投喂）
```plaintext
你是「现实癫文短剧引擎」。我给一套现实内核，你负责把它癫化，但绝不能丢掉现实锚点。
【现实锚点】：张阿姨式极省、帮衬子女、保单小字、垃圾袋碎片、高糖口服液。
【癫化类型】：赛博朋克 / 规则怪谈 / 修仙。
【硬性约束】：
1. 一句话创意，不超过 60 字。
2. 有反常设定 + 日常生活质感 + 致命反差反转。
3. 严禁温情说教、严禁换皮不换逻辑。
4. 输出格式：类别｜一句话灵感｜现实锚点｜癫点｜可扩展大钩子。
```

## 二、故事创作二十三线卡（长篇不崩骨架）

长篇短剧必须**“先锁命题，再锁编码，最后填表”**，严防写到第 30 集断线。

### 2.1 命题矩阵结构
1. **主命题**：全剧核心价值观冲撞（如：过度节俭不是美德，而是两代人互相帮衬的错位悲剧）。
2. **辅助命题一**：契约与人情的撕裂（老一辈信口头，年轻人信白纸黑字）。
3. **辅助命题二**：退休后价值感代偿（老人怕无用，专吃虚荣画饼）。
4. **辅助命题三**：损失厌恶的双标（买菜争三毛，理财被割数十万）。

### 2.2 叙事线索五层织网
- **主线**：核心冲突事件的发展与不可逆升级（如：买房首付被吞，维权无门）。
- **明支线 A（小钱坑）**：日常微小损失与测试（如：药水牛肉、狗不吃测毒）。
- **明支线 B（身体坑）**：危害扩散到下一代（如：高糖口服液引爆家庭矛盾）。
- **明支线 C（群体坑）**：熟人入伙养老床位，社会关系网全面沦陷。
- **大暗线（物证升级）**：一个可重复出现的物理动作（如：儿媳三次下楼扔垃圾，袋子破裂掉落的物证逐级升级：保单碎片 → 空糖瓶 → 变质菜根）。

## 三、四十二层·十九层全息洋葱引擎

在构建 80~100 集复杂长篇或世界观剧集时，逐层自查清单：

| 层级 | 检查核心 | 致命翻车点 |
| :--- | :--- | :--- |
| **L1~L5 世界观与物理法则** | 资源稀缺性、底层运行逻辑、货币体系 | 战力崩塌、凭空变出解法 |
| **L6~L10 身份与阶层锚定** | 权力结构、主角表面身份 vs 真实暗线 | 主角万能、无压迫感 |
| **L11~L15 人物原欲与代价格局** | 角色到底想要什么？为目标愿意牺牲什么？ | 工具人反派、没有动机使坏 |
| **L16~L19 终局与因果闭环** | 结局是否由开局种下的第一颗种子引爆？ | 机械降神、大团圆说教 |

## 四、黄金 3 秒开局与断章钩子法则

### 4.1 黄金 3 秒开场三板斧
1. **巴掌与动作钩**：前 0.5 秒发生物理动作冲撞（如耳光、协议撕碎砸脸、摔门而入）。
2. **身份逆位钩**：画面呈现最底层弱势，声音或神情展现绝对上位压迫。
3. **生死倒计时钩**：一开局把最坏结果亮给观众（如：倒计时 10 秒氧气耗尽、还有 3 分钟行刑）。

### 4.2 集尾断章卡点（Cliffhanger）
- **禁止纯情绪断章**（无意义的怒吼、流泪，观众容易弃剧）。
- **必须提供新信息或新危机**：在每集最后一句话或最后一个动作，抛出观众从未料到的第三种可能（如：刚要签合同，在对方西装袖扣里发现了已故父亲的遗物）。

## 五、自心写作系统（五感八触台词质感）

- **杜绝 AI 味台词**：严禁出现“这怎么可能”、“你竟敢如此”、“你到底是什么人”等空洞网文口癖。
- **五感写实注入**：
  - 嗅觉：霉味、便宜药水味、消毒水夹杂着廉价茉莉香精。
  - 触觉：塑料袋勒进手指泛白、风油精擦在太阳穴的冰刺感。
  - 道具驱动：不要说“他很穷”，写“他拿指甲把牙膏皮从尾端刮了三遍，再用剪刀剪开内壁”。
