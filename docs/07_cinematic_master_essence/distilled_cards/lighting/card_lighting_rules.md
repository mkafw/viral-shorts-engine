# 卡片：影视光位法则、光比控制与材质质感
来源：books/lighting/风光摄影进阶：驾驭光线.epub · books/lighting/光的语言
适用：分镜光影 | 角色立体感 | 情绪氛围 | 材质质感

## 可执行规则

### 1. 核心光位体系与戏剧功能
短剧分镜【光影】字段必须明确单一主光源方位，避免全场发灰：
1. **伦勃朗光 / 前侧光 (45° Key Light)**：
   - 阴影侧面颊形成标志性倒三角光斑。
   - 功能：最经典的立体人物雕刻光，赋予角色深邃、内敛的气质。
2. **正侧光 / 侧逆光 (Side / Rim Light)**：
   - 强烈的明暗分界线（Split Lighting），或者金黄/银白轮廓光将角色从暗沉背景中剥离。
   - 功能：制造正邪两面性、内心纠扎、决断时刻或神圣觉醒。
3. **逆光剪影 (Backlight Silhouette)**：
   - 角色背对强光源，面部处于完全或半阴影，外轮廓光溢出。
   - 功能：神秘降临、深不可测的反派、孤独背影或史诗级开场。
4. **顶光 / 区域聚光 (Top / Spotlight)**：
   - 光线垂直打在头顶与肩部，眼窝凹陷阴影浓重。
   - 功能：审讯、极度压迫、绝望、罪孽审判。
5. **漫射柔光 (Soft Diffused Light)**：
   - 阴天、纸窗、薄纱过滤，无明显硬边缘阴影。
   - 功能：温情回忆、平静日常、疗愈或虚弱状态。

### 2. 光比（Contrast Ratio）与情绪映射
- **高反差大光比 (High Contrast / Chiaroscuro)**：光比 ≥ 8:1。阴影深黑浓重，适配复仇、黑化、对决、惊悚。
- **中度电影光比 (Cinematic Ratio)**：光比 4:1 ~ 3:1。保留面部暗部层次与微弱反光，适配主线剧情推进。
- **低反差小光比 (Low Key Soft / High Key)**：光比 ≤ 2:1。面部通透柔润，适配唯美言情与梦境。

## 提示词片段（可粘贴）

### 常用光影描述模板（可直接填入 10s 分镜）

#### 1. 宿命对峙 / 黑化（冷暖对冲与轮廓光）
- **中文**：冷蓝色月光充当主逆光勾勒人物发丝与肩线边缘，侧前方暖橙色残烛微弱照亮半张脸庞，形成冷暖色温冲突与鲜明割裂感，面部阴影极深。
- **Prompt (EN)**：cinematic high-contrast lighting, cold blue moonlight as strong rim light separating hair and shoulder silhouette, warm amber candlelight softly grazing side of face, dramatic chiaroscuro shadow, 8k.

#### 2. 英雄登场 / 破晓觉醒（体积光与神圣逆光）
- **中文**：破晓晨光穿透残破门窗缝隙，形成肉眼可见的金黄色体积丁达尔光束，微小尘埃在光柱中飘荡，逆光漫射泛开柔和辉光。
- **Prompt (EN)**：golden morning dawn rim light, volumetric God rays / Tyndall effect penetrating through window gaps, visible floating illuminated dust particles, soft glowing halation, epic atmosphere.

#### 3. 绝望审判 / 逼问（顶光硬影）
- **中文**：头顶正上方单色冷硬工业射灯垂落，眼眶与鼻翼下方投射浓黑深渊般阴影，锁骨与下颌线被冷白光切割得棱角分明。
- **Prompt (EN)**：harsh single overhead spotlight, deep shadowy eye sockets, intense top-down contrast, cold stark lighting, psychological interrogation tone.

## 禁忌
- 严禁全景与人物同时亮白无阴影（平光如证件照，丧失电影立体感）。
- 严禁出现与场景不合逻辑的鬼影光源（例如昏暗地牢中面部却通体雪白）。
- 严禁忽略皮肤次表面散射（Subsurface Scattering, SSS）：若无光线穿透耳廓或指尖的微弱血色半透明感，角色会呈现塑料硅胶假人质感。
