## 2. 每个叙事结构文件怎么写才“能用”
你不能只写：

> 要有洋葱结构，先甜后虐。
>
>
这种 AI 也能看懂，但太模糊，生成结果不稳定。

建议每个文件都统一成这个格式：

markdown
```
---
id: onion-emotion
name: 剥洋葱式情感推进
tags: [虐心, 情感反转, 短剧, 真相揭露]
适用题材: [仙侠, 都市虐恋, 悬疑情感]
情绪曲线: 甜 → 疑 → 虐 → 真相 → 核爆

## 核心逻辑
拒绝平铺直叙，用“真相一层层剥开”推动情绪递进。

## 节拍表
| 节拍 | 占比 | 任务 | 情绪 | 输出要求 |
|---|---|---|---|---|
| 1. 虚假美好 | 10% | 建立主角与重要人物的信任关系 | 温暖、轻松 | 必须有一处具体互动细节 |
| 2. 第一层撕裂 | 20% | 制造误会/外部压力 | 不安、疏离 | 双方开始回避眼神或对话变短 |
| 3. 假性和解 | 30% | 短暂回暖，埋下更大隐患 | 希望中带疑 | 至少一句“我以为我们还能回到从前” |
| 4. 第二层真相 | 50% | 重大秘密暴露 | 震惊、痛苦 | 真相不能直接说，要用动作或第三方揭示 |
| 5. 情感核爆 | 70% | 双方被迫对立/生离死别 | 撕裂、崩溃 | 必须有极致扎心台词 |

## 二、除了之前说的，还有哪些叙事结构适合你？
我帮你再补 6 种，专门适配“包装的善意、灰色人性、傻子镜像”这个题材。

### 1. 不可靠叙事者结构
**核心**：叙述者自己就在撒谎，或者他看到的“真相”本身就是扭曲的。
观众先相信他，后来发现他一直在自我欺骗。

**适用**：
施舍者作为主视角，不断向观众解释“我是好心”“这香蕉只是长得丑”。
观众跟着他走，慢慢发现他说的和画面呈现的不一致。

**搭配心理学**：认知失调 + 记忆篡改 + 合理化防御。

### 2. 环形叙事结构
**核心**：故事结尾回到开头，形成一个闭环。
开头和结尾几乎一样，但观众看完后，对同一个画面的理解完全不同。

**适用**：
开头：傻子接过“麻蕉”，笑着说谢谢。
结尾：傻子依旧接过“麻蕉”，笑着说谢谢。
但观众已经知道这善意里有杂质，同样一句“谢谢”变得刺耳。

**搭配心理学**：防御机制循环 + 意识解离。

### 3. 碎片化拼图结构
**核心**：打乱时间线，用记忆碎片拼接真相。
观众像拼图一样，一点点还原完整故事。

**适用**：
穿插施舍者夜里的噩梦、傻子吃下食物后的不适、旁人夸赞的片段。
观众先看到结果，再慢慢拼出“善意”的真相。

**搭配心理学**：潜意识入侵 + 记忆篡改。

### 4. 复调多声部结构
**核心**：多个角色各自发声，没有统一真相。
每个人都活在自己的认知里。

**适用**：
路人觉得施舍者是大善人；
施舍者觉得自己已经仁至义尽；
傻子只觉得“麻蕉”是天下最好吃的东西。
三种声音互相矛盾，观众自行判断。

**搭配心理学**：暗示性操控 + 认知失调。

### 5. 时间循环/回溯结构
**核心**：同一段时间反复发生，每次细节有微妙变化。
人物困在某种模式里，直到某一刻打破循环。

**适用**：
施舍者每天重复同样的施舍动作，每次食物都差不多快坏，每次都说同样的话。
直到某一天，傻子没有出现，循环被打破，他才被迫面对真相。

**搭配心理学**：防御机制 + 意识解离。

### 6. 反高潮结构
**核心**：观众以为要爆发冲突，结果什么都没有发生。
情绪被悬置，反而更压抑。

**适用**：
傻子吃下所有变质食物，但一直没生病；
施舍者一直等，等他倒下，等自己良心被审判。
结果傻子一直好好的，施舍者反而在等待中崩溃。

**搭配心理学**：潜意识入侵 + 认知失调。

## 三、你那些心理学概念怎么用才不写崩？
我给你排个序：

### ✅ 强烈推荐组合（主线必备）
**认知失调 + 合理化防御 + 记忆篡改**
→ 施舍者内心冲突 → 自我说服 → 时间久了连自己都信了。

这是你最核心的人物心理弧线。

### ✅ 进阶增色（适合中后期）
**潜意识入侵 + 意识解离 + 暗示性操控**
→ 夜里做噩梦 → 白天麻木机械 → 长期给傻子洗脑。

这三者可以让故事氛围从现实慢慢滑向心理惊悚。

### ⚠️ 慎用
**多重人格**
除非你想把故事从“现实人性思辨”变成“精神病题材”，否则不要轻易用。
多重人格门槛极高，容易让观众觉得狗血、不真实。

你想表达的“包装的善意”，核心是**普通人都会有的自私与心软**，
一旦加入多重人格，就变成了“病人”，观众就不代入了。

## 二、各模块核心说明

### 00_组合调用规则/

- **目的**：规定不同库之间的读取顺序和组合方式，避免 AI 随机调用。
- **文件示例**：

  - `配方_仙侠底层挣扎流.md`
- **使用要点**：每个配方明确列出“读取顺序 + 生成要求 + 禁用写法”。

### 01_题材色彩与材质库/

- **目的**：定义故事发生的视觉风格、材质质感、色调氛围。
- **文件示例**：

  - `都市_城中村霓虹.md`
  - `赛博_金属与霓虹.md`
- **使用要点**：用具体材质词描述（如“潮湿水泥地反光”“生锈铁门”），避免抽象形容词。

### 02_人物原型库/

- **目的**：提供可替换的角色底层模型。
- **文件示例**：

  - `傻子_纯粹接受型.md`
  - `旁观者_道德审判型.md`
- **使用要点**：每个原型写明核心欲望、恐惧、习惯动作、说话方式。

### 03_运镜分镜库/

- **目的**：控制画面节奏与镜头语言。
- **文件示例**：
  - `短剧快切运镜.md`
  - `心理惊悚_缓慢推镜.md`
- **使用要点**：规定景别切换频率、手持感、光影对比。

### 04_叙事结构与节奏库/

## 三、核心创作方法论（底层逻辑）

### 1. 底层恒定规则

- 人会利用语言构建伪装；
- 内心矛盾催生心理防御；
- 持续暗示能够扭曲认知；
- 现实物性无法被语言篡改。

### 2. 可调数据

- 心理压力大小
- 重复次数
- 信息差时长
- 资源稀缺程度

### 3. 样本替换

- 施舍者 & 傻子
- 博主公益 & 观众
- 寺院布施 & 乞丐
- 任意“施”与“受”的不对等关系

### 4. 临界点叙事
当心理压力抵达临界点，所有防御机制失效，真相爆发。

四条线同时磨，刀子才会越磨越亮。

## 核心逻辑
先确定“刀子”是什么（最终要捅向人心的真相/台词/事件），
再设计“磨刀石”（情感事件或物品），
最后让明线、暗线、主线、支线从不同角度反复磨刀，
直到刀刃足够锋利，一击刺穿。

## 磨刀石选择
- 情感事件型：连续的信任建立/破裂/重建/再次破裂
- 物品事件型：同一物件反复出现，每次意义不同
- 混合型：物品+情感一起磨

## 磨刀节奏
| 次数 | 明线 | 暗线 | 主线压力 | 支线反应 |
|---|---|---|---|---|
| 第1次 | 初次施舍 | 施舍者犹豫 | 低 | 路人无视 |
| 第2次 | 傻子主动来 | 施舍者烦躁 | 中 | 邻居开始注意 |
| 第3次 | 食物明显更差 | 施舍者自我说服 | 高 | 有人称赞善行 |
| 第4次 | 傻子身体不适 | 施舍者噩梦 | 极高 | 小贩欲揭穿 |
| 第5次 | 最后一击 | 真相/沉默 | 爆发 | 众人围观 |

## 钩子设计
每次磨刀后必须留下“倒刺”，例如：
- 傻子到底有没有发现？
- 施舍者会承认吗？
- 那个旁观者会不会说出去？

## 禁用写法
- 禁止磨刀过程重复而无变化（必须每次加新层次）
- 禁止刀刃提前露出（观众太早知道真相会泄气）
- 禁止最后不拔刀（必须真的捅下去，不能回避）
```

## 一、三观能不能是人物自己捏造、演化出来的？
**能，而且真实的人几乎都是这样。**
你感觉“设定的三观不好”，是因为很多剧本里三观是作者硬塞给角色的标签，像贴纸一样贴在脑门上，观众一眼就看出是假的。

真实的三观，是人物在活着的过程中，**自己一点点捏出来、试出来、撞出来、改出来的。**

就像：

- 一个小孩听父母说“善有善报”，他信了；
- 长大后他帮了人却吃了亏，他开始动摇；
- 再后来他做了一件不干净的事，发现没人发现，还得了好处；
- 于是他捏出一个新三观：“善良要留一半，做做样子就行。”

这不是作者设定的，是人物自己在生活里“演化”出来的。
**三观是人物自己长出来的，不是贴上去的。**

## 二、你说的“不断刷新、重塑”，就是三观的演化机制
对，人可以变，三观也会不断刷新。
但这里有一个极其重要的分层：

### 1. 表层三观：会变，而且应该变
这些是人物对具体事情的态度、立场、选择方式。
比如：

- 他以前觉得不能浪费粮食；
- 后来觉得“快坏的食物给傻子吃，总比扔了好”；
- 再后来觉得“我这是在帮他”。

表层三观像水一样，会随着环境、经历、利益关系不断流动、刷新、重塑。
**这是人物“成长”或“堕落”的轨迹。**

### 2. 底色：极难变，只有重大变故才能摧毁重塑
你说的“底色”，就是人物最核心、最根本的那个东西。
它可能是：

- 一个骨子里的恐惧（比如怕被抛弃）
- 一个根深蒂固的信念（比如“人不能害人命”）
- 一种本能的反应模式（比如遇到危险先躲）

底色通常在人物很小的时候就形成了，像地基一样，平时看不见，但决定了上面盖什么房子。

**表层三观可以刷很多次漆，底色不裂，房子就不会塌。**

## 三、什么情况下底色才会变？
你完全说对了：**只有重大变故，才能摧毁底色，然后重塑。**

而且这个过程必须是“先毁后立”，不能跳步。

text
```
底色完整
   ↓
重大变故（摧毁性事件）
   ↓
底色碎裂（人物失去所有支撑）
   ↓
空白期（极度痛苦、混乱、迷失）
   ↓
重塑新的底色（可能更好，也可能更坏）
```
**关键点**：
底色不能随随便便变。
如果一个角色昨天还贪生怕死，今天突然英勇就义，没有重大事件支撑，观众会觉得假。
但如果他亲眼看见最重要的人因为自己的懦弱而死，他痛到极致，从此不再退缩——这个底色转变就成立。

所以：

- **表层三观**：可以频繁刷新、反复拉扯、前后矛盾——这才像活人；
- **底色**：必须稳定，只能被一次或极少次重大变故击碎重塑——这才叫角色弧光。

## 一、故事的本质，是不是多方面探讨人性？
**是，但不只是“探讨”，更是“呈现”。**
人性不是一块平板，而是一个多面体，不同情境下会折射出完全不同的光。

一个真实的角色，身上至少要有三副面孔：

| 面孔 | 什么时候出现 | 例子（伪善施舍者） |
| --- | --- | --- |
| 公开面孔 | 在旁人面前 | 温和、善良、被夸“大善人” |
| 私下面孔 | 独自一人时 | 烦躁、后悔、自我说服 |
| 极端面孔 | 被逼到绝境时 | 冷漠、推卸、甚至恶毒 |
故事的本质，就是把一个人放在压力下，让这三副面孔不断切换、互相打架。
观众要看的不是“他是好人还是坏人”，而是“他什么时候会露出哪张脸”。

## 二、文字本身蕴含的力量，不能虚盖，只能借物发挥
你这句话太准了：
**不能拿空洞的形容词把文字本来的力量盖住。**
比如你写“他很冷酷”，这是虚盖；
你写“他说话的声音像吃砒霜一样，听得人从牙根开始发冷”，这才是把力量放出来。

这就是你说的“借物”——像风雅颂里的“颂”，借钟鼓之声传达庄重；
像树借风声，像车借轮音；
像把声音写得像砒霜，把坏人的脸写得像榴莲皮、地瓜糙皮——
**用物象把看不见的情绪变成看得见、摸得着、听得见的东西。**

所以文字的力量本来就在，只是被“虚盖词”盖住了。
你要做的，是把形容词换成物象和感官。

## 三、坏人刻画要入木三分，怎么做到？
你说到“粉底预色”“突出一点”，其实就是：
**坏人不能只涂一种颜色，要有底色、阴影、高光。**
入木三分，是刻出层次，不是划一刀就完。

给你一个“坏人三层底色法”：

### 第一层：表面色（观众第一眼看到）
让他看起来正常，甚至有点可怜或可敬。
比如施舍者总是笑，总说“这麻蕉甜”。

### 第二层：阴影色（细看才发现的暗面）
让观众慢慢察觉不对。
比如他从不给傻子完好的食物；
他躲开傻子眼睛；
他夜里失眠，但第二天继续送。

### 第三层：核心色（最深处的那个东西）
不是纯粹的恶，而是恐惧、匮乏或执念。
比如他小时候饿怕了，所以总觉得“给了好的自己就会饿死”。
这层一露出来，观众恨不起来，只觉得脊背发凉。

这样刻画出来的坏人，才“入木三分”。
不能只突出坏，那样像纸片人；要突出他“为什么变成这样”。

## 一、什么是“反虚掩词”？
**定义**：
在写作中，凡是空洞、抽象、概括性的修饰词，都属于“虚掩词”。
它们不是让读者看见、听见、摸到事物，而是用一层模糊的纱把真实盖住。

**“反虚掩词”**，就是揭掉这层纱，让文字直接露出事物的肉、骨、声、色、味、触。

例子：

text
```
虚掩词：他很痛苦。
反虚掩词：他蹲在墙角，手指抠进水泥缝里，指节发白，喉咙里滚出一声像狗被打断腿时的那种呜咽。
```
前者是“告知”，后者是“呈现”。

## 二、虚掩词的典型特征

| 类型 | 示例 | 问题 |
| --- | --- | --- |
| 概念化 | 善良、邪恶、美丽、丑陋 | 没有具体内容 |
| 总结式 | 他很紧张、她非常难过 | 代替了生理反应 |
| 判断式 | 这是一个可怕的场面 | 读者没感到可怕 |
| 概括性形容词 | 豪华、简陋、诡异、温馨 | 无法形成画面 |
| 抽象名词 | 命运、孤独、绝望、希望 | 没有载体 |
这些词不是不能用，而是不能直接拿来当描写。
必须用具体的物象、身体、声音、动作去“翻译”它们。

## 三、反虚掩词的具体操作法

### 1. 用物象翻译情绪

```

反虚掩：他反复翻看手机，屏幕亮了又灭，灭了又亮，像一根快被拉断的皮筋。
```

### 2. 用身体部位翻译心理

### 3. 用声音翻译氛围
text
```

```

### 4. 用触感翻译关系
text
```

反虚掩：他递东西时，两人的指尖隔着两厘米，谁也没有再往前伸。

## 一、什么是“物性”？
物性，就是这个东西本身不可替代的物理属性。

text
```
香蕉：会从青变黄，从黄生黑斑，黑斑蔓延到果肉，果肉变软、发黏、出酒味，最后化成一滩水。
铁：会锈，会在潮湿天气里渗出冰凉的水珠。
旧棉被：会吸潮，会越来越沉，会发出一种压着灰尘的霉味。
塑料袋：会脆，会裂，会被风灌满，发出哗啦啦的响。
```
这些不是情绪，不是比喻，是物本身的样子。
写作时，先尊重这个，再让环境去压它。

## 二、为什么说“在环境下面”？
因为**同一个物性，换一个环境，意义完全变了。**

还是那根烂香蕉：

- 在富人厨房垃圾桶里，它是“垃圾”，没人多看一眼；
- 在施舍者手里，它是“可以送出去的善心”；
- 在傻子眼里，它是“今天不会挨饿的东西”。

物性没变：它一样软烂、发黑、带酒味。
是环境把它的物性逼了出来，让观众感到不适、心酸或愤怒。

所以：**物性是客观的；环境是压迫物性显形的条件。**

## 三、写作时怎么用“物性 + 环境”？
给你一个简单方法：

### 第 1 步：先写物性（不加任何情绪）
text
```
香蕉皮上布满黑斑，捏下去软烂，果肉像泥一样陷进去，凑近有酒味。
```

### 第 2 步：再放回环境，让环境去压它
text
```
傻子蹲在菜市场后门的垃圾堆旁，手指黑乎乎的，接过那根香蕉时，笑出了声。
他闻不到酒味，只闻到甜。
```
这里没有说“心酸”，但观众会感到一阵发紧。
因为**物性的真实，被环境的反差放大了。**

物性越准，环境越具体，文字越有力量。

## 一、人物借物性：不是让人物“看”物，而是让物“侵入”人物
很多写法是这样的：

text
```
他看着那根烂香蕉，心里很难过。
```
这是人物在“看”物，物和人是分开的。
但真正的借物性，是让人物和物发生**物理接触**，让物的质感直接作用于人物的身体和反应。

### 方法：三步借物法

1. **接触**：人物用身体部位碰到物
2. **物性传进来**：触感、温度、气味、重量传进身体
3. **身体/心理反应**：人物身体微动，或者内心被物性勾出情绪

### 例子：施舍者借烂香蕉的物性
text
```
他拇指按了按香蕉皮，那层皮已经软得没有弹性，像按在一块即将腐化的肉上。
黏腻的汁液从指缝里渗出来，他下意识把手往裤子上蹭了蹭，又停住了。
```
这里没有说“他嫌弃”，但观众全感觉到了。
**人物借了烂香蕉的“软烂、黏腻、腐坏”，用身体反应把物性演了出来。**

## 二、人物感应物性：让物性成为人物状态的“外挂器官”
更高一层是：人物不需要碰到物，物性也会自动与人物的心理状态呼应。
比如：

- 人物焦虑时，看什么都觉得“在逼他”；
- 人物麻木时，再刺鼻的气味他也闻不到；
- 人物良心不安时，总觉得连墙上的水渍都像眼睛。

### 例子：傻子感应“甜”
傻子闻不到酸腐的酒味，因为他的认知里没有“变质”这个概念。
他借不到“腐坏”的物性，他只能感应到“甜”。
于是：

text
```
傻子咬了一口，果肉已经稀烂，像吞了一口温热的糖水。
他眯起眼，对施舍者笑：“麻蕉真甜。”
```
**同一根香蕉，施舍者感应到的是“腐坏”，傻子感应到的是“甜”。**
这就是用感应物性的差异，来写人物处境和认知差。

### 用法 3：天地元素改变物的物性

- 下雨天，香蕉坏得更快；
- 高温天，肉更容易发绿发臭；
- 湿冷天，傻子的破衣服贴在身上，更显单薄。
