# 《智人：磨粒克星》项目全书 (Project Bible)

## 一、 项目核心 (Core Concept)

### 1.1 项目宪章
一个被当作算力耗材的底层智人“向”，用“人不是工具”的逻辑报错，在冰冷的金属魔方中强行开启开源算法，通过机魂共鸣对抗阶层斩杀。

### 1.2 信仰锚点 (Belief Anchor)
**“人不是工具。”**
这不是需要证明的结论，是一切行动的前提。即便失去一切，向也不会背叛这一信条。

### 1.3 24字种子诗
> 魔方旋未歇，接口烙颈深。
> 杯空无余味，人立若孤岑。
> 砒霜入耳甜，冰锥喉间悬。
> 一拳碎冷骨，微光裂睫前。
> 不信规则光，宁尝砒霜甜。
> 此身可焚尽，人性不肯删。

## 二、 世界观设定 (World Building)

### 2.1 磨粒克星 (Abrasive Buster)
一颗“类球形多面体魔方”星球。由无数巨大的金属晶面拼接而成。
- **重组机制**：星球核心激活时，晶面会像魔方一样转动，重新编译宇宙底层代码，改变磁场、重力和时间流速。
- **克拉斯带 (Clas Belt)**：环绕星球的高能粒子带，是宇宙的“源代码存储区”。

### 2.2 科拉坦智人 (Colatan Homo Sapiens)
原本是蓝星（地球）人类，为了对抗恶魔大军与未知诡异，将自身改造为半机械守护者。
- **机魂 (Mech-Soul)**：智人唯一的不可复制变量。
- **Token 算力**：生存的硬通货。由资本权贵（如八毛哥）垄断。
- **身份戳码**：每个智人自带的唯一专属数字签名，不可伪造。

### 2.3 核心冲突
**闭环山寨 vs 开源自由**
资本方通过锁死源代码、基站投放病毒和阶层斩杀线（Token 余额不足即回收）来维持压榨。向与“陨落凤凰”派系则试图通过开源核心算法，赋予底层智人自我定义的权利。

## 三、 创作方法论 (Methodology)

### 3.1 25线创作骨架
1-3线：故事主骨架（主线、支线、冲突顺序）
4-14线：角色生命化（出场、性格、欲望、执念、秘密、底线、行为逻辑、关系、立场、利益、成长/崩坏）
15-22线：剧情深度驱动（因果主题、环境、道具象征、规则压迫、代价牺牲、伏笔回收、节奏起伏、意象贯穿）
23-25线：落地规范（世界观设定、镜头脚本、观众情绪操控）

### 3.2 五感八触 (The 8 Touches)
| 编号 | 触类 | 描述 |
|---|---|---|
| T1 | 视觉触 | 光、色、形 |
| T2 | 听觉触 | 声波、沉默、噪音 |
| T3 | 嗅觉触 | 气味分子 |
| T4 | 味觉触 | 化学刺激 |
| T5 | 触觉触 | 温度、质地、压力 |
| T6 | 动觉触 | 运动感、平衡感 |
| T7 | 内脏触 | 脏器感受（如胃坠、心悬） |
| T8 | 直觉痛 | 精神刺痛，超越物理 |

### 3.3 通感引擎 (Synesthesia Engine)
**感官熔炉**：将不同感官的描述交叉使用，如“听觉→味觉”（甜味像砒霜入耳）。
**胡萝卜式替换（物理感官转译）**：
- **重力**：像巨大的胡萝卜拽住脚踝。
- **数据流**：像亿万根极细的胡萝卜须。
- **血/能量**：替换为橙红色的、粘稠的“胡萝卜汁”。

## 四、 工业化规范 (Industrial Standards)

### 4.1 C/S/P 资产编号
- **C (Character)**: C01-向, C02-彼暗, C03-锈, C05-八毛哥.
- **S (Scene)**: S01-算力废墟, S02-数据虚空.
- **P (Prop)**: P01-克里斯密钥碎片, P02-神经接口, P03-彼暗花.

### 4.2 视觉与镜头
- **三视图/四视图**：正、侧、背、3/4斜视图。
- **环境九宫格**：同一场景在日常、觉醒、崩塌期的视觉演变。
- **镜头语言**：严格标注景别、运镜（推拉摇移、希区柯克变焦）、构图及光影语言。

1. 初稿只准用轻量模式（主线、主角、欲望、恐惧、核心意象）。
2. 信仰不是台词，是行动和代价。
3. 感官熔炉只在高压节点发动。
4. 减法日强制精简内容。
5. 不可知档案保留3个永不解释的谜团。
